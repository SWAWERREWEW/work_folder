Ограничение времени	1 секунда
Ограничение памяти	256 Мб
Ввод	стандартный ввод или input.txt
Вывод	стандартный вывод или output.txt
Условие задачи
Дан набор спутниковых/аэрофотоснимков поверхности с кратерами https://disk.yandex.ru/d/2qp-Kum04Fb-CA. Для каждого изображения тестового набора необходимо предсказать бинарную маску сегментации кратеров в формате RLE (двухклассовая сегментация: пиксель = кратер / не кратер).

Обучающая выборка: craters/train/ (изображения + YOLO-метки .txt, класс 0 — кратер).
Валидационная: craters/valid/ — та же структура.
Тестовый набор: изображения без разметки; для них нужно сгенерировать маски-предсказания.
Скоринг (метрика)
Метрика — F1 (Dice) по попиксельному совпадению бинарных масок, усреднённая по всем изображениям (как в Kaggle RLE-челенджах сегментации):

Формат файла-ответа/предсказаний (CSV)
Двухколоночный CSV: FILE_NAME,TARGET 010_png.rf.fcf5e274562ee69a325f9d7a0b30767f.jpg,59 34 507 82 699 34 1147 82 ...

Необходимо провести «Анализ результатов работы модели», включающий следующие пункты:

Проведите не менее трёх экспериментов с разными гиперпараметрами (например, learning rate, размер батча, эпохи, разморозка слоев архитектуры). Составьте таблицу результатов. На основе метрик выберите наилучший вариант для финального обучения. Для финальной модели выполните детальный анализ результатов:

a) Анализ по размеру объектов — разбейте результаты на три категории: Small, Medium, Large (в соответствии со стандартом COCO). Оцените, насколько хорошо модель справляется с объектами разного размера. Особое внимание уделите маленьким кратерам? (5 баллов)
