# Перед выполнением необходимо загрузить 


Ограничение времени	1 секунда
Ограничение памяти	256 Мб
Ввод	стандартный ввод или input.txt
Вывод	стандартный вывод или output.txt
Цель - обучить модель нейронной сети, которая сможет классифицировать изображения животных по видам (панда, тигр, жираф и т.д.)

Вам предоставлен набор данных с тысячами изображений различных животных. Ваша модель должна предсказать соответствующую метку животного для каждого нового изображения. Описание данных

Набор данных содержит размеченные изображения животных. Формат представления: Изображения в формате .jpg различных размеров. Обучающий набор (train): Включает в себя файлы изображений, в названия файла вписан класс изображения Тестовый набор (test): Набор изображений без разметки. Ваша задача — предсказать метку для каждого изображения в этом наборе. Метрика Ваши решения будут оцениваться по метрике Accuracy (доля правильных ответов). Необходимо добиться качества accuracy выше 50%.

##Формат файла для отправки Ваш файл с предсказаниями должен быть в формате CSV и содержать ровно два поля FILE_NAME - название файла изображения из тестовой набора TARGET - предсказанная метка класс: 0,1,…13 (классы изображений заданы в файле class_names.csv) Файл предсказаний (submission) должен иметь следующую структуру: FILE_NAME,TARGET f1.jpg,1 f2.jpg,2 f3.jpg,0 f4.jpg,1 f5.jpg,13 f6.jpg,0
