Задача: Stacking для классификации (Forest Covertype)
Формат ввода
Датасет: forest_covertype.csv
Цель
Построить ансамбль моделей в виде stacking-классификатора на основе RandomForestClassifier и добиться качества по метрике 
ROC-AUC не ниже 0.85 на тестовой выборке.
План решения
Загрузка данных.
Считать датасет из файла forest_covertype.csv в табличный формат (например, DataFrame).
Очистка данных.
Удалить дубликаты наблюдений.
Удалить выбросы (по заранее выбранной стратегии: IQR, z-score, отсечение по квантилям и т.п.).
Проверка зависимости признаков.
Оценить зависимость признаков между собой (например, через корреляцию для числовых признаков и/или меры зависимости для категориальных).
Удаление признаков с высокой зависимостью.
Исключить признаки, имеющие высокую взаимозависимость (например, при 
∣ρ∣≥τ,
где τ — выбранный порог).
Кодирование категориальных признаков.
Закодировать признаки с типом object (например, One-Hot Encoding или другой подходящий метод кодирования).
Формирование матрицы признаков и целевой переменной.
Разделить данные на:
X∈Rn×pиy∈{0,1}n (или многоклассовая разметка)X∈R n×p иy∈{0,1} n  (или многоклассовая разметка)
где n — число объектов, p — число признаков.
Разделение на обучающую и тестовую выборки.
Выполнить разбиение на подвыборки:
(Xtrain,ytrain), (Xtest,ytest)(X train​ ,y train​ ), (X test​ ,y test)
При необходимости использовать стратификацию по целевому признаку.
Создание стэка моделей RandomForestClassifier.
Сформировать ансамбль в подходе stacking:
Базовые модели: несколько экземпляров RandomForestClassifier (например, с разными гиперпараметрами).
Мета-модель (final estimator): классификатор, обучающийся на предсказаниях базовых моделей.
Обучение классификатора.
Обучить stacking-модель на обучающей выборке:
ˆf=fit(Xtrain,ytrain)
Оценка качества по ROC-AUC.
Получить вероятности/скоры на тестовой выборке и вычислить:
ROC-AUC(ytest,ˆs(Xtest))
где ˆs(⋅) — оценка вероятности класса (или score). Для многоклассового случая использовать подход ovr/ovo и соответствующий вариант расчёта ROC-AUC.
Условия прохождения теста
ROC-AUC≥0.85
