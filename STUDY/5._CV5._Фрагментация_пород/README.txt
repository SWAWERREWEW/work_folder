5. CV5. Фрагментация пород
Ограничение времени	1 секунда
Ограничение памяти	256 Мб
Ввод	стандартный ввод или input.txt
Вывод	стандартный вывод или output.txt
Цель: построить модель сегментации, которая автоматически находит и выделяет каждый фрагмент горной породы на фотографиях. (https://disk.yandex.ru/d/2qp-Kum04Fb-CA)

Дано множество фотографий разного происхождения (карьерные съёмки, сетки абразивоструйной обработки, взрывные работы, вид с БПЛА, складские зоны). Каждое изображение содержит от нескольких единиц до сотен камней разной формы и размера.

Единственный класс: stone.

Формат посылки
Файл — CSV с заголовком. Каждая строка описывает один обнаруженный объект:

FILE_NAME,CONFIDENCE,TARGET
openpits_10.bmp,0.92,0 0.123 0.045 0.151 0.051 0.148 0.087 0.119 0.079 0.123 0.045
setka_IMG_20250204_091905.jpg,0.78,0 0.510 0.220 0.543 0.211 0.555 0.234 0.520 0.245 0.510 0.220
Столбец	Описание
FILE_NAME	Имя файла изображения (как в тестовой папке)
CONFIDENCE	Уверенность модели, 0 ≤ conf ≤ 1
TARGET	class_id x₁ y₁ x₂ y₂ … xₙ yₙ — координаты вершин полигона, нормализованные к [0, 1] (деление пикселей на ширину/высоту изображения). class_id = 0.
Метрика
Оценка — mAP@[0.50 : 0.05 : 0.95] (среднее Average Precision по 10 порогам IoU от 0.50 до 0.95 с шагом 0.05, формула COCO). В ноутбуке к решению показан (baseline) пример на YOLO Segm и формирование предсказания. Можно использовать любые другие оригинальные подходы: Instance Segmentation, Mask RCNN, Foundation Model. За оригинальность решения дополнительные баллы.
