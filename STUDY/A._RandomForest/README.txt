Задача: Random Forest для предсказания оттока
В этой задаче вам нужно построить модель классификации на основе случайного леса и оценить её качество по метрикам Recall, Accuracy и ROC-AUC.

Формат ввода
Датасет находится в файле:
churnclean.csv
churnclean.csv
Файл доступен в каталоге с решением (как входной файл контеста).

Требования к решению
Выполните последовательно следующие шаги:

Загрузите данные из churnclean.csv.
Удалите выбросы (способ удаления выбросов выберите самостоятельно и опишите в коде).
Закодируйте признаки interplan, vmailplan, churn булевыми значениями (True/False или 0/1).
Разделите данные на признаки X и целевую переменную y (целевая переменная — churn).
Разделите данные на обучающую и тестовую выборки.
Создайте классификатор:
RandomForestClassifier
(n_estimators=50,class_weight="balanced")
RandomForestClassifier(n_estimators=50,class_weight="balanced")
Обучите классификатор с помощью кросс-валидации со следующими параметрами:
cv=5,scoring=’recall’
Найдите среднее значение Recall по кросс-валидации и сохраните его в переменную cv_score.
Найдите стандартное отклонение Recall по кросс-валидации и сохраните его в переменную cv_stdev.
Найдите значение Accuracy на тестовой выборке и сохраните его в переменную accuracy.
Обучите RandomForestClassifier для значений n_estimators от 20 до 100 с шагом 20:
n_estimators∈{20, 40, 60, 80, 100}
Для каждого значения n_estimators вычислите метрику ROC-AUC (на тестовой выборке) и сохраните значения в список rocauc_list, где
rocauc_list[i] соответствует n_est[i]
Сформируйте список n_est (количество деревьев), соответствующий перебираемым значениям n_estimators.
Постройте график зависимости ROC-AUC от количества деревьев: x=n_est, y=rocauc_list, x=n_est,y=rocauc_list
Определите количество деревьев, при котором достигается максимальный Recall (на тестовой выборке), и сохраните это значение в переменную optimal_n_est.
Критерии прохождения задания
Решение считается корректным, если выполняются условия:
cv_score ≥ 0.47
cv_stdev ≤ 0.06
accuracy ≥ 0.90
А также в решении присутствуют и корректно сформированы переменные:
n_est, rocauc_list, optimal_n_est

Формат вывода
Явный вывод в стандартный поток stdout не требуется, если контест проверяет значения переменных в коде.

Если требуется печать значений, выведите 5 строк в следующем порядке:

cv_score
cv_stdev
accuracy
n_est (как список)
rocauc_list (как список)
optimal_n_est
